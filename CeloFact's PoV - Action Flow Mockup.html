Structured Extraction — Free-Text PO Item procurement-pov
Blueprint ⌄
Celonis — Watch Trigger
Step 1
What it does: detects in near real time the creation of a new "Create Free-Text Requisition Item" on the Knowledge Model, and automatically starts the flow.
Celonis — HTTP Request
Step 2 · to ML Workbench
What it does: sends the free-text description to the script hosted in ML Workbench (via the native Action Flow ↔ ML Workbench webhook). The script extracts category, quantity, unit of measure, and suggested vendor, along with a confidence score.
Celonis — Router
Step 3 · conditional branch
What it does: evaluates the confidence score returned by the model and routes the flow down one of the two paths below, with no logic needed outside Celonis.
High confidence
Low confidence
Celonis — Update Augmented Attribute
Step 4A
What it does: automatically writes the extracted fields (category, quantity, vendor) onto the PO Item, making it eligible for automatic Purchase Order creation without buyer involvement.
Outcome: automatic creation
No further module required
The PO Item continues down the standard, already-automated path in Celonis for "Create Purchase Order Item" → "Send Purchase Order," with no manual fallback.
Celonis — Create Task
Step 4B
What it does: creates a Task assigned to the buyer, with the fields suggested by the model already pre-filled (category, quantity, vendor) to confirm or correct in one click, instead of filling everything in manually from scratch.
Celonis — Send Email
Step 5B
What it does: emails the assigned buyer that a new Task is ready for review, with a direct link — speeding up pickup compared to sitting passively in a queue.
